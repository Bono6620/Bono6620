# موقع شجرة العائلة

موقع كامل لأرشيف العائلة بالعربي (RTL)، شغال بـ PHP + MySQL، ومظبوط عشان يشتغل على استضافة InfinityFree المجانية.

> **عندك موقع ووردبريس؟** فيه نسختين تانيين جاهزتين لموقع `elkharbotly.rf.gd`:
> - [`wordpress-theme/`](wordpress-theme/) - **قالب (theme) كامل** يتحكم في شكل الموقع كله من Appearance > Themes - دي النسخة الموصى بيها حاليًا.
> - [`wordpress-plugin/`](wordpress-plugin/) - نفس المميزات بالظبط لكن كإضافة (plugin) تتركب فوق قالب موجود.
>
> النسخة دي (اللي في الجذر) نسخة مستقلة (standalone) لاستضافة InfinityFree عادية من غير ووردبريس.

## المميزات

- **تسجيل دخول لكل الموقع**: محدش يشوف أي حاجة من غير ما يعمل تسجيل دخول.
- **3 مستويات صلاحيات**:
  - **مدير**: كل الصلاحيات + إدارة المستخدمين (يضيف/يمسح مستخدمين ويحدد صلاحياتهم).
  - **محرر**: يضيف ويعدل ويمسح المحتوى (الأفراد، الملفات، الأحداث، الوثائق) لكن مايقدرش يدير المستخدمين.
  - **مشاهدة فقط**: يشوف كل حاجة بس مايقدرش يعدل ولا يضيف ولا يمسح.
- **تبويب الشجرة**: عرض شجرة العائلة بصريًا (بطاقة لكل فرد فيها صورة، الاسم، سنة الميلاد/الوفاة)، مع صفحة تفاصيل لكل فرد وخانة بحث بالاسم.
- **تبويب الملفات**: أرشيف ملفات عام (صور، PDF، Word، Excel، ZIP) لأي حاجة تخص العائلة.
- **تبويب الأحداث الزمنية**: تايم لاين لأحداث العائلة المهمة مرتبة بالتاريخ، وكل حدث ممكن يترط بفرد معين.
- **تبويب الوثائق**: أرشيف خاص لحجج الوقف والورث وأي وثائق تانية، كل وثيقة ليها نوع (وقف / ورث / أخرى)، تاريخ، وصف، وملف مرفق (صورة أو PDF).
- **أمان**: كل الاستعلامات Prepared Statements، الفورمات محمية بـ CSRF token، كلمات السر مشفرة (bcrypt)، وملفات الوثائق والملفات العامة متحمّلة عن طريق سكريبت بيتأكد من تسجيل الدخول قبل ما يديها لحد (مش رابط مباشر مكشوف).

## هيكل الملفات

```
config.php            إعدادات قاعدة البيانات واسم الموقع
schema.sql             أوامر إنشاء الجداول + بيانات تجريبية
login.php / logout.php تسجيل الدخول والخروج
tree.php / member.php  الشجرة وصفحة تفاصيل الفرد
files.php               تبويب الملفات
timeline.php             تبويب الأحداث الزمنية
documents.php            تبويب الوثائق
users.php                إدارة المستخدمين (للمدير بس)
download.php             تحميل الملفات/الوثائق بعد التأكد من تسجيل الدخول
includes/                كود مشترك (قاعدة البيانات، الصلاحيات، الهيدر والفوتر)
assets/                  CSS و JS والصور
uploads/                 صور الأفراد + uploads/documents و uploads/files (محمية بـ .htaccess)
```

## خطوات النشر على InfinityFree

جربت أدخل بنفسي على لوحة تحكم InfinityFree بالبيانات اللي بعتها عشان أرفع الموقع مباشرة، بس InfinityFree بتمنع أي دخول آلي (bot/automation) للوحة التحكم كإجراء حماية من الاستضافات المجانية، فمعنديش وصول مباشر لرفع الملفات. الخطوات اللي جاية بسيطة وهتاخد منك حوالي 10 دقايق بس.

### 1) اعمل قاعدة بيانات MySQL

- ادخل على لوحة تحكم InfinityFree (Client Area) باليوزر والباسورد بتاعتك.
- روح لقسم **MySQL Databases**.
- اعمل قاعدة بيانات جديدة (لو مفيش واحدة موجودة بالفعل)، وسجّل عندك: اسم السيرفر (Hostname)، اسم قاعدة البيانات، اليوزرنيم، والباسورد.

### 2) استورد جدول البيانات

- من نفس الصفحة افتح **phpMyAdmin**.
- اختار قاعدة البيانات، وروح لتاب **Import**.
- ارفع ملف `schema.sql` الموجود في المشروع ده ونفّذه (زرار Go/تنفيذ).
- ده هيعمل كل الجداول (`users`, `members`, `events`, `documents`, `files`) وهيضيف حساب مدير تجريبي وبيانات تجريبية للشجرة والأحداث والوثائق.

### 3) عدّل ملف `config.php`

افتح `config.php` (من عندك، أو مباشرة من File Manager بعد الرفع) وحط بيانات قاعدة البيانات اللي سجلتها فوق:

```php
define('DB_HOST', 'sqlXXX.infinityfree.com');
define('DB_NAME', 'if0_XXXXXXXX_familytree');
define('DB_USER', 'if0_XXXXXXXX');
define('DB_PASS', 'كلمة السر بتاعتك');

define('SITE_NAME', 'عائلة الاسم بتاعك');
define('SITE_URL', 'https://your-site.infinityfreeapp.com');
```

### 4) ارفع الملفات

عن طريق **File Manager** في لوحة تحكم InfinityFree (أو برنامج FTP زي FileZilla، بيانات الـ FTP هتلاقيها تحت **FTP Accounts**):

- ارفع **كل** محتويات المشروع ده جوه فولدر `htdocs`.
- تأكد إن فولدرات `uploads`, `uploads/documents`, `uploads/files` اترفعوا كاملين بملفات `.htaccess` اللي جواهم (دي بتحمي صور وملفات العائلة من إن أي حد يوصلها من غير تسجيل دخول).

### 5) افتح الموقع وغيّر كلمة السر

- افتح رابط موقعك، هيوديك على صفحة تسجيل الدخول.
- سجّل دخول بالحساب التجريبي:
  - **اسم المستخدم:** `admin`
  - **كلمة السر:** `ChangeMe123!`
- على طول من قايمة اسمك فوق يمين، ادخل **تغيير كلمة السر** وغيّرها لحاجة تانية بس انت اللي تعرفها.
- بعدين من **إدارة المستخدمين** ضيف حسابات لباقي أفراد العائلة وحدد لكل واحد صلاحيته (محرر أو مشاهدة فقط).
- امسح البيانات التجريبية (الأفراد والأحداث والوثائق التجريبية) وابدأ ضيف بيانات عائلتك الحقيقية.

## ملاحظات أمان

- غيّر كلمة سر المدير الافتراضية فورًا، ومتشاركش بيانات `config.php` أو بيانات دخول الاستضافة مع حد.
- الوثائق والملفات مش متاحة إلا لمستخدم مسجل دخول بالموقع (مش مجرد رابط عام).
- لو حسيت إن حد وصل لحسابك، غيّر كلمة سر المدير وكلمة سر قاعدة البيانات فورًا.

## التشغيل محليًا (اختياري، لو حابب تجرب قبل الرفع)

لو عندك PHP و MySQL على جهازك:

```bash
php -S localhost:8000
```

وعدّل `config.php` يشاور على قاعدة بيانات محلية بدل InfinityFree.
