# موقع شجرة العائلة

موقع بسيط لعرض شجرة عائلة بالعربي، شغال بـ PHP + MySQL، ومظبوط عشان يشتغل على استضافة InfinityFree المجانية.

## المميزات

- عرض شجرة العائلة بشكل بصري (بطاقة لكل فرد فيها صورة، الاسم، وسنة الميلاد/الوفاة).
- صفحة تفاصيل لكل فرد (الأب، الأم، الزوج/الزوجة، الأبناء، نبذة).
- خانة بحث بالاسم فوق الشجرة.
- لوحة تحكم للأدمن (`/admin`) لإضافة/تعديل/حذف الأفراد ورفع صورهم، محمية بتسجيل دخول.
- الموقع بالكامل RTL ومصمم يشتغل كويس على الموبايل.

## هيكل الملفات

```
config.php          إعدادات قاعدة البيانات واسم الموقع
schema.sql           أوامر إنشاء الجداول + بيانات تجريبية
index.php            الصفحة الرئيسية (الشجرة)
member.php           صفحة تفاصيل فرد
includes/            كود مشترك (اتصال قاعدة البيانات، الدوال، الهيدر والفوتر)
admin/                لوحة تحكم الأدمن
assets/               CSS و JS والصور
uploads/              صور أفراد العائلة (بيتملي أوتوماتيك من لوحة التحكم)
```

## خطوات النشر على InfinityFree

### 1) اعمل حساب واعمل موقع جديد

- سجّل في [infinityfree.com](https://infinityfree.com) واعمل موقع جديد (Add Website)، هياخد شوية وقت لحد ما يتفعّل.

### 2) اعمل قاعدة بيانات MySQL

- من لوحة تحكم InfinityFree (Client Area) روح على **MySQL Databases**.
- اعمل قاعدة بيانات جديدة، وسجّل عندك: اسم السيرفر (Host)، اسم قاعدة البيانات، اليوزر، والباسورد.

### 3) استورد جدول البيانات

- افتح **phpMyAdmin** من لوحة التحكم.
- اختار قاعدة البيانات اللي عملتها، وروح لتاب **Import**.
- ارفع ملف `schema.sql` الموجود في المشروع ونفّذه.
- ده هيعمل جدولين (`admins` و `members`) وهيضيف حساب أدمن تجريبي وبيانات عائلة تجريبية.

### 4) عدّل ملف `config.php`

افتح `config.php` وحط بيانات قاعدة البيانات اللي سجلتها في الخطوة 2:

```php
define('DB_HOST', 'sqlXXX.infinityfree.com');
define('DB_NAME', 'if0_XXXXXXXX_familytree');
define('DB_USER', 'if0_XXXXXXXX');
define('DB_PASS', 'كلمة السر بتاعتك');

define('SITE_NAME', 'عائلة الاسم بتاعك');
define('SITE_URL', 'https://your-site.infinityfreeapp.com');
```

### 5) ارفع الملفات

عن طريق **File Manager** في لوحة تحكم InfinityFree أو برنامج FTP زي FileZilla:

- ارفع كل محتويات المشروع جوه فولدر `htdocs`.
- تأكد إن فولدر `uploads` اترفع كامل (فيه ملف `.htaccess` بيمنع تشغيل أي سكريبت جواه لحماية الموقع).

بيانات FTP (لو هتستخدم FileZilla) هتلاقيها في لوحة تحكم InfinityFree تحت **FTP Accounts**.

### 6) افتح الموقع وغيّر كلمة سر الأدمن

- افتح رابط موقعك، المفروض تشوف الشجرة التجريبية.
- روح على `/admin/login.php` وسجّل دخول بالحساب التجريبي:
  - **اسم المستخدم:** `admin`
  - **كلمة السر:** `ChangeMe123!`
- على طول ادخل **تغيير كلمة السر** وغيّرها لحاجة تانية، وامسح البيانات التجريبية من لوحة التحكم وابدأ ضيف عائلتك الحقيقية.

## ملاحظات أمان

- كل الاستعلامات بتستخدم Prepared Statements ضد SQL Injection.
- الفورمات فيها حماية CSRF token.
- الصور اللي بترفع بيتم التحقق من نوعها وحجمها.
- غيّر كلمة سر الأدمن الافتراضية فورًا، ومتشاركش بيانات `config.php` مع حد.

## التشغيل محليًا (اختياري، لو حابب تجرب قبل الرفع)

لو عندك PHP و MySQL على جهازك:

```bash
php -S localhost:8000
```

وعدّل `config.php` يشاور على قاعدة بيانات محلية بدل InfinityFree.
