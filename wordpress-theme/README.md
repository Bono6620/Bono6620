# قالب أرشيف العائلة (Family Archive) - ووردبريس

قالب ووردبريس (WordPress theme) كامل - مش إضافة (plugin) - مبني خصيصًا لموقع `elkharbotly.rf.gd`. القالب ده هو اللي بيتحكم في شكل الموقع كله من **Appearance > Themes**، بدل ما يكون شغال جنب قالب تاني.

> فيه نسخة إضافة (plugin) في مجلد [`wordpress-plugin/`](../wordpress-plugin/) بنفس المميزات بالظبط، لو حابب تركّبها كإضافة فوق قالب موجود بدل ما تستبدل القالب بالكامل.

## المميزات

- **تصميم مودرن كامل**: هيدر بتدرج لوني، تابات بخط سفلي (underline)، أيقونات SVG مخصصة (مش إيموجي)، بانر (hero) في أول صفحة الشجرة بيعرض اسم العائلة وعدد الأفراد وعدد الأجيال، كروت بحواف وظلال ناعمة، صور بإطار متدرج اللون.
- **الموقع كله محمي بتسجيل دخول** - ما حدش يشوف أي حاجة من غير ما يعمل تسجيل دخول بحساب ووردبريس.
- **إدارة المستخدمين والصلاحيات جاهزة من ووردبريس نفسه**:
  - **مدير (Administrator)**: كل الصلاحيات.
  - **محرر الأرشيف** (`family_editor`): يضيف/يعدل/يمسح أفراد وملفات وأحداث ووثائق.
  - **مشاهدة فقط** (`family_viewer`): يشوف بس، مفيش أي زرار تعديل أصلاً.
- **4 تبويبات رئيسية**: الشجرة، الملفات، الأحداث الزمنية، الوثائق (وقف/ورث/أخرى).
- **صفحة "حسابي"**: كل مستخدم بيشوف بياناته وصلاحيته، وبيقدر يغيّر كلمة السر بنفسه من غير ما يدخل لوحة تحكم ووردبريس.
- **صفحة "لوحة التحكم"** (Administrator بس) بتصميم سايدبار حقيقي:
  - **المستخدمون**: يضيف مستخدم جديد، يغيّر صلاحية أي حد، يمسح أي حساب - كل ده من غير الدخول للوحة تحكم ووردبريس الافتراضية.
  - **إضافة محتوى**: فورمات سريعة لإضافة فرد/حدث/وثيقة/ملف مباشرة من نفس الصفحة.
- **الوثائق والملفات محمية**: بتتخزن برا مجلد `uploads` العام، وتحميلها بيتطلب تسجيل دخول.
- **التحكم عن بعد (API)**: نفس واجهة الـ REST API المؤمّنة بمفتاح سري الموجودة في نسخة الإضافة.

## التثبيت

1. حمّل ملف `family-archive-theme.zip` (مرفق منفصل).
2. من لوحة تحكم ووردبريس: **المظهر (Appearance) > قوالب (Themes) > أضف جديد (Add New Theme) > رفع قالب (Upload Theme)**.
3. اختار ملف الـ zip واضغط **تثبيت الآن (Install Now)**، وبعدها **تفعيل (Activate)**.

**مهم**: القالب ده بديل كامل للقالب الحالي بتاع موقعك، مش إضافة بتتركب فوقه - بمجرد التفعيل هو اللي هيتحكم في شكل الموقع كله.

بمجرد التفعيل، القالب أوتوماتيك:
- بيعمل 6 صفحات (الشجرة، الملفات، الأحداث الزمنية، الوثائق، حسابي، لوحة التحكم) بقوالب العرض المناسبة لكل واحدة.
- بيخلي صفحة "الشجرة" هي الصفحة الرئيسية للموقع.
- بيظبط روابط الموقع (Permalinks).
- بيعمل صلاحيتين جديدتين (محرر الأرشيف / مشاهدة فقط).

لو القالب مفعّل عندك بالفعل وبترفع نسخة أحدث فوقه، أي صفحة جديدة بتتعمل أوتوماتيك أول ما حد يفتح الموقع - مش محتاج خطوة يدوية.

**لا يوجد أي خطوة قاعدة بيانات يدوية** - القالب بيستخدم نظام ووردبريس نفسه لتخزين البيانات.

## بعد التفعيل

1. افتح الموقع، هيوديك على صفحة تسجيل الدخول بتاعة ووردبريس.
2. سجّل دخول بحسابك (elkharbotly).
3. من قايمة اسمك فوق يمين اختار **"لوحة التحكم"**، وبعدين **"المستخدمون"** - ضيف حسابات لباقي أفراد العائلة واختار لكل واحد **الصلاحية** مباشرة.
4. ابدأ ضيف أفراد العائلة من تبويب "الشجرة" (زرار "+ إضافة فرد")، أو من **"لوحة التحكم" > "إضافة محتوى"**.
5. ضيف الأحداث والوثائق والملفات بنفس الطريقة.
6. كل مستخدم (بما فيهم انت) يقدر يغيّر كلمة السر بنفسه من صفحة **"حسابي"**.

## هيكل الملفات

```
style.css                 اسم وبيانات القالب (Theme Name...) + كل التصميم (CSS)
functions.php              نقطة التحميل - بيستدعي كل ملفات inc/
header.php / footer.php    الهيكل العام (<html>...<body> و </body></html>)
index.php / 404.php        قوالب احتياطية
page-templates/            قالب عرض مخصص لكل صفحة (الشجرة، الملفات، ...)
inc/
  icons.php                 مجموعة أيقونات SVG مخصصة (بدل الإيموجي)
  post-types.php             تعريف أنواع المحتوى (فرد، حدث، وثيقة، ملف)
  roles.php                   الصلاحيات (محرر الأرشيف / مشاهدة فقط)
  uploads.php                 تخزين الملفات الآمن
  meta-boxes.php               فورمات إضافة/تعديل المحتوى في لوحة تحكم ووردبريس
  tree-data.php                 منطق بناء شجرة العائلة
  template-functions.php        الهيدر والتابات وعرض كل صفحة من الصفحات الأربعة
  account.php                    صفحة "حسابي"
  admin-panel.php                 صفحة "لوحة التحكم"
  access.php                       تسجيل الدخول الإجباري وتحميل الملفات المحمية
  remote-api.php                    واجهة الـ API للتحكم عن بعد
  setup.php                          إنشاء الصفحات عند التفعيل
assets/                    JS والصور
```

## ملاحظات أمان

- كل الاستعلامات والفورمات بتستخدم آليات ووردبريس الأساسية للحماية (nonces، capability checks، `$wpdb`/`WP_Query` الآمنة).
- ملفات الوثائق والملفات العامة بتتخزن في `wp-content/family-archive-private/` (محمي بملف `.htaccess` يمنع الوصول المباشر) وبتتنزل بس عن طريق سكريبت بيتأكد من تسجيل الدخول أولاً.
- غيّر كلمة سر حسابك لو حسيت إن حد شافها.
